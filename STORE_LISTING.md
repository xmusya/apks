# Groq AI Chat

- **Name:** Groq AI Chat
- **Package Name:** `com.aistudio.groqchat.fxmpzq`
- **Source Code:** https://github.com/xmusya/apks (папка `groq-ai-chat/`)
- **License:** MIT
- **Summary:** High-performance Groq AI chat client with live token and speed stats

**Description:**

Groq AI Chat is a fast, native Android client for the Groq API, built with Jetpack Compose and Material 3 Expressive.

Features:

- Chat with Groq-hosted models (Llama, Mixtral, Gemma and others), with a model picker and custom model support
- Live tokens-per-second, latency and token usage statistics per session and overall
- Local chat history stored on the device (Room database)
- Streaming responses
- Custom API base URL and model parameters (temperature, max tokens, system prompt)
- Adaptive dual-pane layout for tablets and foldables

Your Groq API key is stored locally on your device and is sent only to the Groq API endpoint you configure.

# Transmify

- **Name:** Transmify
- **Package Name:** `com.aistudio.transmify.app`
- **Source Code:** https://github.com/xmusya/apks (папка `transmify/`)
- **License:** MIT
- **Summary:** Remote control and stats for Transmission with RuTracker search

**Description:**

Transmify is a Transmission remote client for Android with a Material 3 Expressive interface.

Features:

- Manage multiple Transmission servers and switch between them quickly
- Add torrents by magnet link, `.torrent` file or URL
- Live download/upload speed, progress, ETA and per-torrent details
- Seeding statistics and notifications for completed downloads
- Built-in RuTracker search to find magnets and add them to Transmission
- Demo/sandbox mode to try the UI without a server

Transmify is only a remote control for a Transmission daemon that you host yourself. It does not include, host or distribute any content.
